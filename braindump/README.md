# Braindump - Source Materials for Incubation

This folder is for raw materials that feed Phase 0 (INCUBATE).

## What Goes Here

Add any accumulated materials you want processed:

- **AI conversation exports** - ChatGPT, Claude, etc.
- **Voice memo transcriptions**
- **Notes and ideas** - text files, markdown
- **Reference projects** - links, descriptions
- **Screenshots with ideas**
- **"Someday" notes** - things you've been saving

## Structure

```
braindump/
├── source-materials/           # Put your files here
├── incubation-insights.md      # (Generated by Phase 0)
├── prior-art-dna.md            # (Patterns from local codebases)
└── dream-synthesis.md          # (AI creative synthesis)
```

## Incubation Process

When ready, tell Claude: "Run incubation" or use `/incubate`

This triggers Phase 0 (Cognitive Incubation):
1. **Material Absorption** - Extract explicit and implicit ideas from your files
2. **Local Codebase Discovery** - Scan ~/dev/projects/claude/* and ~/dev/projects/codex/*
3. **Pattern Extraction** - Find transferable patterns from prior implementations
4. **Creative Synthesis** - AI builds deep understanding before capture

After processing, you'll have structured insights ready for Phase 1 (CAPTURE).

## Skip If

- Fresh idea with no accumulated materials
- Prefer to start with raw capture first
- Just say "skip incubation" or "start with capture"
