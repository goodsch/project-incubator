# Phase 0.0: Meta-Analysis (Optional)

## When to Use

Use this phase when the braindump materials are **already structured**:
- ChatGPT conversation outputs (pre-synthesized)
- Existing specifications or design docs
- Prior analysis or frameworks
- Multiple organized documents with clear themes

**Skip this phase** for raw, unstructured braindumps (stream-of-consciousness notes, scattered ideas, etc.).

## Setup

Use `mcp__clear-thought__thoughtbox` for forward thinking (5-8 thoughts).

## Process

### Step 1: Read All Materials

Carefully read everything in `braindump/` folder. Note:
- What frameworks or models already exist
- What technical concepts are defined
- What philosophical foundations are laid
- What specific features or ideas are proposed

### Step 2: Thoughtbox Analysis

Use thoughtbox to extract the architecture:

**Thought 1:** "Core thesis/vision - what is this project fundamentally trying to be?"

**Thought 2:** "Framework inventory - what conceptual models are present?"

**Thought 3:** "Concept relationships - how do these ideas connect to each other?"

**Thought 4:** "Gaps and contradictions - what's missing, unclear, or conflicting?"

**Thought 5:** "Questions for Dream phase - what should creative expansion address?"

### Step 3: Create Concept Map

Optionally create ASCII diagram showing relationships:

```
             MAIN CONCEPT
                  |
     +------------+------------+
     |            |            |
  SUB-A        SUB-B        SUB-C
     |            |
   detail      detail
```

## Key Insight

When braindumps are pre-structured, the Dream phase becomes **dialectical** - pushing AGAINST the existing synthesis rather than just extracting from raw material. The meta-analysis sets up what needs to be challenged.
