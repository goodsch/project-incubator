# Phase 0.3: Wild Imagination

## Setup

Use `mcp__clear-thought__mental_models` to retrieve:
1. `constraint-relaxation` model
2. `inversion` model

## Process

### Step 1: Constraint Relaxation

**Remove all limits and dream freely:**

"If you had unlimited time..."
- [What would you build?]

"If you had unlimited money..."
- [What would you create?]

"If you had magic..."
- [What would exist?]

"If failure was impossible..."
- [What would you attempt?]

"If you could break any rule..."
- [What rule would you break and why?]

**Capture the WILDEST version** - no judgment, no "but that's impossible."

### Step 2: Inversion

**What would guarantee failure?**

List 5-7 ways this project could definitely fail:
1. "It would fail if..."
2. "It would fail if..."
3. "It would fail if..."
4. "It would fail if..."
5. "It would fail if..."

**Now flip each one:**
1. Failure → Opportunity: ...
2. Failure → Opportunity: ...
3. Failure → Opportunity: ...
4. Failure → Opportunity: ...
5. Failure → Opportunity: ...

### Step 3: Perspective Shifts

**The Child:** How would a 7-year-old approach this? What would they want it to do? What would make them say "COOL!"?

**The Visionary:** If this project changed the world, how? What's the boldest claim you could make?

**The Critic:** What would a harsh critic say is missing? What's the obvious flaw you're ignoring?

**The User:** Forget what YOU want - what would make a user's day? What would make them tell their friends?

**The Artist:** If this was art, what would it express? What emotion would it evoke?

### Step 4: Random Provocations

Ask these questions and capture whatever emerges:

- "What if this was a game?"
- "What if this was a ritual?"
- "What if this was a secret?"
- "What if this was alive?"
- "What if this was temporary?"
- "What if this was ancient?"
- "What if this was from the future?"

### Step 5: Capture Everything

**NO FILTERING** - write down every idea, even:
- Absurd ideas
- "Impossible" ideas
- Ideas that contradict each other
- Ideas that scare you
- Ideas that excite you
