# Phase 6: SEED

## Purpose

Generate the complete, ready-to-use Claude Code project directory based on all previous phases and the configuration determined in Phase 5.

## Prerequisites

- Phase 5 (CONFIGURE) must be complete
- All configuration files in `config/`
- User has approved the configuration

## Input Files

Read these from the project directory:
- `config/summary.md` - Overall configuration
- `config/skills.md` - Skills to include
- `config/mcp.md` - MCP server recommendations
- `config/hooks.md` - Hooks to include
- `config/context.md` - Context pattern
- `spec/vN.md` - Final specification
- `decisions/architecture.md` - Architecture decisions

## Output Structure

**Generate in:** `output/`

```
output/
├── CLAUDE.md                 # Project instructions with Clear Thought
├── CONTEXT.md                # User scratchpad (from context pattern)
├── README.md                 # Human documentation
├── .claude/
│   ├── settings.json         # Permissions + hooks
│   ├── skills/
│   │   ├── skill-rules.json  # Auto-activation rules
│   │   └── [skills]/         # Skill directories
│   ├── commands/
│   │   └── [commands].md     # Slash commands
│   └── agents/
│       └── [agents].md       # Subagents
├── docs/
│   ├── PRD.md                # Final PRD
│   ├── ARCHITECTURE.md       # Technical design
│   └── WORKFLOW.md           # Vibe coding guide
└── src/                      # Scaffolded source
    └── [per architecture]
```

### Step 6: Copy/Generate Skills

For each skill in config/skills.md:

**From Library:**
1. Copy skill directory structure
2. Adapt content if noted in config
3. Update trigger patterns for this project

**Custom Skills:**
1. Create skill directory
2. Generate SKILL.md from config outline
3. Add to skill-rules.json

**Generate skill-rules.json:**
```json
{
  "version": "1.0",
  "skills": {
    // Entry for each skill with triggers
  }
}
```

### Step 7: Generate Commands

For each command in config:

1. Create command .md file
2. Include proper frontmatter
3. Document process steps

### Step 8: Copy/Generate Agents

For each agent in config:

1. Copy from library OR
2. Generate custom agent
3. Adapt paths as needed

### Step 9: Copy Hooks (if included)

1. Copy hook files (.sh, .ts)
2. Copy package.json
3. Note: Don't run npm install (user will do)

## Gate Criteria

Phase 6 is complete when:
- [ ] Output directory created
- [ ] All files generated
- [ ] Validation checklist passes
- [ ] User has reviewed the output

## What NOT to Do

- Don't skip the Clear Thought section in CLAUDE.md
- Don't generate without consulting config files
- Don't leave placeholder text
- Don't skip validation
- Don't forget hook dependencies note
