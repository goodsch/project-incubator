# /seed - Phase 6

Generate the complete output project - ready to build.

## Prerequisites

- Phase 5 (CONFIGURE) complete
- Configuration approved

## Process

### 1. Create Output Directory Structure

```
output/
├── CLAUDE.md
├── CONTEXT.md
├── README.md
├── .claude/
│   ├── settings.json
│   ├── skills/
│   │   ├── skill-rules.json
│   │   └── [skills]/
│   ├── commands/
│   │   └── [commands].md
│   └── agents/
│       └── [agents].md
├── docs/
│   ├── PRD.md
│   ├── ARCHITECTURE.md
│   └── WORKFLOW.md
└── src/
    └── [scaffolded structure]
```

### 2. Generate CLAUDE.md

From config/claude-md-content.md

### 3. Generate CONTEXT.md

```markdown
# {Project Name} - Context

## About This Project
{Brief description from PRD}

## Current Status
Project scaffolded and ready for development.

## Key Files
- CLAUDE.md: Project instructions
- docs/PRD.md: Product requirements
- docs/ARCHITECTURE.md: Technical design
- docs/WORKFLOW.md: Development guide

## Notes
{Space for ongoing notes}
```

### 4. Generate README.md

```markdown
# {Project Name}

{Description from PRD}

## Quick Start

1. Clone/copy this directory
2. Install dependencies: {command}
3. Start development: {command}
4. Run `claude` to get AI assistance

## Features

{Feature list from PRD}

## Tech Stack

{From architecture}

## Documentation

- [Product Requirements](docs/PRD.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Development Workflow](docs/WORKFLOW.md)

## Development

{Key commands and workflows}

---

Generated by Project Incubator
```

### 5. Generate Skills, Commands, Agents

For each item in config:
- Copy from library OR generate custom
- Create skill-rules.json

### 6. Generate Documentation

**docs/PRD.md:** Copy final spec version
**docs/ARCHITECTURE.md:** Copy architecture document
**docs/WORKFLOW.md:**

```markdown
# Development Workflow

## Getting Started

1. Open this directory in your terminal
2. Run `claude` to start Claude Code
3. Claude will read CLAUDE.md automatically

## Development Flow

### Starting a Feature
1. Describe what you want to build
2. Claude will guide implementation
3. Review and approve changes

### Common Commands
{Command table from config}

### When You're Stuck
- Ask Claude for help
- Use Clear Thought for complex decisions
- Check docs/ for context

### Best Practices
- Small, incremental changes
- Test frequently
- Commit working states
- Ask Claude to explain unfamiliar code
```

### 7. Scaffold Source Structure

Based on architecture directory structure:
- Create directories
- Add placeholder/starter files
- Include boilerplate from templates

### 8. Validate Output

Check all files present:
- [ ] CLAUDE.md
- [ ] CONTEXT.md
- [ ] README.md
- [ ] .claude/settings.json
- [ ] .claude/skills/skill-rules.json
- [ ] docs/PRD.md
- [ ] docs/ARCHITECTURE.md
- [ ] docs/WORKFLOW.md
- [ ] src/ structure

### 9. Update Notion

Update SEED OUTPUT section with scaffold details.
Update PROJECT SNAPSHOT:
- Status: Ready to Build
- Phase: 6 - SEED (Complete)
