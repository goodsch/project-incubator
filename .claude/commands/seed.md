# /seed

Generate the complete output project.

## Prerequisites

- Phase 5 (CONFIGURE) must be complete
- Configuration must be approved

## Process

1. **Load the phase-seed skill**
   Use Skill tool with skill: "phase-seed"

2. **Create output directory structure**
   ```
   projects/{name}/output/
   ├── CLAUDE.md
   ├── CONTEXT.md
   ├── README.md
   ├── .claude/
   │   ├── settings.json
   │   ├── skills/
   │   │   ├── skill-rules.json
   │   │   └── [skills]/
   │   ├── commands/
   │   │   └── [commands].md
   │   └── agents/
   │       └── [agents].md
   ├── docs/
   │   ├── PRD.md
   │   ├── ARCHITECTURE.md
   │   └── WORKFLOW.md
   └── src/
       └── [scaffolded structure]
   ```

3. **Generate CLAUDE.md**
   From config/claude-md-content.md

4. **Generate CONTEXT.md**
   ```markdown
   # {Project Name} - Context

   ## About This Project
   {Brief description from PRD}

   ## Current Status
   Project scaffolded and ready for development.

   ## Key Files
   - CLAUDE.md: Project instructions
   - docs/PRD.md: Product requirements
   - docs/ARCHITECTURE.md: Technical design
   - docs/WORKFLOW.md: Development guide

   ## Notes
   {Space for ongoing notes}
   ```

5. **Generate README.md**
   ```markdown
   # {Project Name}

   {Description from PRD}

   ## Quick Start

   1. Clone/copy this directory
   2. Install dependencies: {command}
   3. Start development: {command}
   4. Run `claude` to get AI assistance

   ## Features

   {Feature list from PRD}

   ## Tech Stack

   {From architecture}

   ## Documentation

   - [Product Requirements](docs/PRD.md)
   - [Architecture](docs/ARCHITECTURE.md)
   - [Development Workflow](docs/WORKFLOW.md)

   ## Development

   {Key commands and workflows}

   ---

   Generated by Project Incubator
   ```

6. **Copy/generate skills**
   For each skill in config:
   - Copy from library OR
   - Generate custom skill
   - Create skill-rules.json

7. **Copy/generate commands**
   For each command in config:
   - Copy from library OR
   - Generate custom command

8. **Copy/generate agents**
   For each agent in config:
   - Copy from library OR
   - Generate custom agent

9. **Generate documentation**

   **docs/PRD.md:**
   Copy final spec version

   **docs/ARCHITECTURE.md:**
   Copy from decisions/architecture.md

   **docs/WORKFLOW.md:**
   ```markdown
   # Development Workflow

   ## Getting Started

   1. Open this directory in your terminal
   2. Run `claude` to start Claude Code
   3. Claude will read CLAUDE.md automatically

   ## Development Flow

   ### Starting a Feature
   1. Describe what you want to build
   2. Claude will guide implementation
   3. Review and approve changes

   ### Common Commands
   {Command table from config}

   ### When You're Stuck
   - Ask Claude for help
   - Use Clear Thought for complex decisions
   - Check docs/ for context

   ### Best Practices
   - Small, incremental changes
   - Test frequently
   - Commit working states
   - Ask Claude to explain unfamiliar code
   ```

10. **Scaffold source structure**
    Based on architecture directory structure:
    - Create directories
    - Add placeholder/starter files as appropriate
    - Include any boilerplate from templates

11. **Validate output**
    Check all files present:
    - [ ] CLAUDE.md
    - [ ] CONTEXT.md
    - [ ] README.md
    - [ ] .claude/settings.json
    - [ ] .claude/skills/skill-rules.json
    - [ ] docs/PRD.md
    - [ ] docs/ARCHITECTURE.md
    - [ ] docs/WORKFLOW.md
    - [ ] src/ structure

12. **Present completion summary**
    ```
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    🎉 PROJECT GENERATED: {project-name}
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    Location: projects/{name}/output/

    Contents:
    ├── CLAUDE.md (project instructions)
    ├── CONTEXT.md (your notes)
    ├── README.md (human docs)
    ├── .claude/
    │   ├── {X} skills
    │   ├── {Y} commands
    │   └── {Z} agents
    ├── docs/
    │   ├── PRD.md
    │   ├── ARCHITECTURE.md
    │   └── WORKFLOW.md
    └── src/
        └── {scaffolded structure}

    Next Steps:
    1. Copy output/ to your desired location:
       cp -r projects/{name}/output ~/projects/{name}

    2. Navigate there:
       cd ~/projects/{name}

    3. Install dependencies (if any):
       {install command}

    4. Start Claude Code:
       claude

    5. Start building!

    The WORKFLOW.md file has your complete development guide.
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    ```
