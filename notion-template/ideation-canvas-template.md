|------|---------------|------|--------|-------|

### Type Legend
- 💡 New feature idea
- 🐛 Bug or issue noticed
- ✨ Enhancement/improvement
- 🔧 Technical consideration

### Status Legend
- ⏳ Pending - Not yet reviewed
- 🔄 Discussed - Reviewed with Claude
- ✅ Added - Incorporated into project
- ❌ Declined - Not pursuing (with reason)

### How to Use
1. **Anytime**: Add ideas as they come to you (mobile app, voice, desktop)
2. **Session start**: Claude checks this list first
3. **Review together**: Discuss each pending item
4. **Decide fate**: Add to project, queue for later, or decline
5. **Mark processed**: Update status so it's not reviewed again

## How to Create in Notion

When creating a new Ideation Canvas:

1. **Create page** under Project Incubator or linked to a Project
2. **Copy structure** above as starting template
3. **Initialize trackers** with empty tables
4. **Set status** to Phase 1 - Capture
5. **Begin session** with Capture phase questions

## Updating During Session

### After Each User Response

1. Update **Design Schema** with new information
2. Mark **Question Queue** items as answered
3. Add new questions to **Question Queue**
4. Log detected gaps in **Gap Tracker**
5. Note assumptions in **Assumptions Log**
6. Update **Energy Notes** if notable signal

### At Phase Transitions

1. Update **Exploration Progress** checkboxes
2. Review **Gap Tracker** for blockers
3. Update page **Status** callout
4. Consider if ready for next phase

### End of Session

1. Write **Session History** entry
2. Update all tracker statuses
3. Set **Next Steps**
4. Update **Last updated** timestamp

## Status Indicators

Use consistent emoji indicators:

| Indicator | Meaning |
|-----------|---------|
| 🔴 | Empty / Blocking / Critical |
| 🟡 | Draft / Important / In Progress |
| 🟢 | Solid / Minor / Complete |
| ✅ | Done / Confirmed / Validated |
| ❓ | Unknown / Needs Research |
| 🔄 | In Progress |

## Phase Status Format

Update the status callout at top of page:

- `🔄 Phase 1 - Capture | Progress: 10%`
- `🔄 Phase 2 - Clarify | Progress: 25%`
- `🔄 Phase 3 - Expand | Progress: 50%`
- `🔄 Phase 4 - Challenge | Progress: 70%`
- `🔄 Phase 5 - Synthesize | Progress: 85%`
- `✅ Phase 6 - Validate | Progress: 100%`
